<b><p>This was one of my earlier projects, made just for fun while learning front-end dev 🐣. It's a Spotify-style layout — sidebar library, tracklist grid, and a player bar at the bottom with play/pause and track progress.</b></p>

## ✨ Features

- 🏠 Home and search sections in the sidebar
- 📚 "Your Library" list with playable tracks
- 🎵 Tracklist grid with cover art and playlist cards
- ▶️ Bottom player bar showing the current track and controls
- 🔐 Login button on the top right
